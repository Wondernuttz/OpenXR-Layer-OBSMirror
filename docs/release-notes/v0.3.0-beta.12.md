# OpenXR OBS Mirror v0.3.0 Beta 12

Beta 12 adds a native OpenVR/SteamVR capture backend to the existing OBS plugin.
The OpenXR source and all of its recording-only controls remain unchanged.

## New: OpenVR / SteamVR Mirror Capture

- Add **OpenVR / SteamVR Mirror Capture** from OBS's Sources menu to capture
  SteamVR's compositor mirror directly.
- Select the left eye, right eye, or both eyes side by side.
- Crop any edge by percentage or automatically fill the OBS recording canvas.
- Reconnect to SteamVR from source properties without restarting OBS.
- Multiple source instances share one reference-counted OpenVR background
  connection and release every mirror texture before shutting the runtime down.

The implementation uses Valve's official OpenVR 2.15.6 SDK and dynamically
loads the packaged `openvr_api.dll` only when an OpenVR source is active. A
missing OpenVR runtime file therefore cannot prevent **OpenXR Mirror Capture**
from loading.

## Installation and diagnostics

- The installer, portable package, setup script, and Control Center plugin
  updater now install and validate the matching `openvr_api.dll` beside
  `win-openxr.dll`.
- OBS logs the OpenVR SDK and SteamVR runtime versions on connection, texture
  dimensions and selected eye mode on source initialization, and actionable
  initialization failures.
- OpenXR overscan, camera smoothing, and quad-layer controls remain specific to
  the OpenXR source because SteamVR's mirror is already composited.

## Install or update

Close OBS Studio before updating so both plugin files can be replaced, then run
`OpenXR-OBSMirror-0.3.0-beta.12-Setup.exe`. Restart OBS and add the capture
source matching the application's runtime API.
